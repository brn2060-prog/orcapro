Este aparelho

Com 5 celulares: cada um conta uma parte da adega. No fim, cada aparelho toca em Exportar JSON e envia o arquivo (WhatsApp, e-mail…). No celular principal, use Juntar contagem com cada arquivo recebido — as quantidades são somadas automaticamente.

Exportar e juntar

O JSON leva o catálogo completo (com fotos) — é ele que você usa para juntar aparelhos e para integrar em outro sistema. O CSV abre no Excel.

Recomeçar

“Zerar quantidades” mantém os itens cadastrados (com fotos) e volta tudo para 0 — ideal para a próxima contagem. “Apagar tudo” remove também o catálogo.
